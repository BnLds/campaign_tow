## Acceptance Criteria

1. **AC1** — TanStack CLI initializes the project with the correct directory layout, add-ons, and scripts.
2. **AC2** — Vitest + Playwright added manually; `pnpm test` passes with a placeholder test; `pnpm build` succeeds.
3. **AC3** — GitHub Actions CI pipeline runs lint → typecheck → vitest on every PR.
4. **AC4** — Railway auto-deploys on push to `main`; app accessible via HTTPS.
5. **AC5** — `DATABASE_URL`, `SESSION_SECRET`, `ADMIN_PASSWORD_HASH` set as Railway env vars; DB health check on startup; no secrets in repo.
6. **AC6** — `src/styles/globals.css` has palette CSS custom properties; Cinzel + Inter woff2 files in `public/fonts/`.
