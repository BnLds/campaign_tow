# Epic List

## Epic 1: Project Foundation & Player Authentication
Players can securely access the app. Ben can manage player accounts. The project infrastructure (scaffolding, database, auth, CI/CD, deployment) is in place and operational.
**FRs covered:** FR1, FR2, FR3, FR4, FR6

## Epic 2: Army Setup & Unit Card Consultation
All armies are visible with their unit profiles, base stats, and campaign deltas. Ben can import and manage army data via OWB export or manual entry. Players can view and directly edit unit/character data.
**FRs covered:** FR5, FR8, FR9, FR10, FR11, FR12, FR13, FR14

## Epic 3: Campaign Timeline & Match Management
Players can navigate campaign history via a scrollable timeline, create matches, see pending actions, and record match results. Evolutions are visible on both players' timelines.
**FRs covered:** FR7, FR15, FR16, FR17, FR18, FR19, FR20

## Epic 4: Post-Match Flow & XP Progression
Players can complete the post-match ritual — enter XP unit by unit, discover tier-ups, choose improvements, record character injuries and bonuses. Retroactive entry is supported. This is the core value loop of the app.
**FRs covered:** FR21, FR22, FR23, FR24, FR25, FR26, FR27, FR28, FR29

## Epic 5: Campaign Reference Tables
Any logged-in player can instantly consult campaign rules during a game: XP tables, 2D6 injury/destruction tables, and improvement lists per tier.
**FRs covered:** FR30, FR31, FR32, FR33, FR34
