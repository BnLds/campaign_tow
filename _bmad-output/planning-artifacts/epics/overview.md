# Overview

This document provides the complete epic and story breakdown for the Territory Module of campaign_tow, decomposing requirements from the PRD, Territory UX Design Specification, and Territory Architecture Decision Document into implementable stories.

**Scope:** Territory Module only (feature branch `territoire`). The tactical layer (matches, XP, unit cards, narrative timeline) is already built and is out of scope. This epic breakdown covers the strategic layer: tile management, colony/building construction, faction rules enforcement, CO economy, and initial setup.
