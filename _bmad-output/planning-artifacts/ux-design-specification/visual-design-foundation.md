## Typography System

- **Titres** : Cinzel 600–700 — noms d'armée, noms d'unité, headers
- **Corps / stats** : Inter 400–700 — valeurs numériques, labels, navigation
- Hiérarchie : Nom armée (Cinzel 700, 18–20px) → Nom unité (Cinzel 600, 14–15px)
  → Valeurs stats (Inter 700, 14–16px) → Labels (Inter 600, 9–10px uppercase)

## Spacing & Layout Foundation

- Principe : **aéré** — 3–6 unités max, on peut respirer
- Unité de base : 4px. Padding item : 10–12px vertical, 12–14px horizontal
- Hauteur item liste : ~56–64px (confortable pour tap, lisible au premier regard)
- Zones de tap : minimum 44×44px sur toutes les actions fréquentes

## Accessibility Considerations

- Contraste texte primaire / fond : ratio > 7:1 ✓
- Vert et rouge jamais seuls : toujours accompagnés du signe +/– et/ou du texte
- Zones de tap ≥ 44px mobile
