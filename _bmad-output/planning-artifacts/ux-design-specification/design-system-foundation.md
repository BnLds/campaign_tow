# Design System Foundation

## Design System Choice

**shadcn/ui** (Radix UI + Tailwind CSS). Personnalisation totale, mobile-first
natif, accessibilité intégrée, juste assez pour ~15 utilisateurs.

## Visual Direction

Inspiration Warhammer Battle 90s-2000s — sobre et épuré. L'univers s'exprime
dans les accents, pas dans la surcharge ornementale.

## Unit Card XP Progression

MVP : couleur de bordure uniquement (neutre → bronze → argent → or → or+).
V2 : textures évolutives, effets visuels, illustrations d'unités.

## Customization Strategy

Minimal et ciblé. Composant **UnitCard** = seul composant entièrement custom.
Tous les autres composants restent proches des defaults shadcn/ui.
