# UX Pattern Analysis & Inspiration

## Inspiring Products Analysis

**Old World Builder (OWB)** — référence de vitesse et familiarité. Manques comblés
par Campaign TOW : deltas de campagne, historique de progression, visibilité croisée.

**Cartes Magic : The Gathering** — personnalité visuelle forte par unité.
Format adopté pour la vue détaillée, accessible en un tap depuis la liste.

**Instagram Feed** — timeline chronologique inverse, scroll naturel et narratif.
Chaque partie = un "post" autonome avec date, adversaire, résultat, évolutions.

## Transferable UX Patterns

- **Liste → Carte** : trouver (liste compacte) puis lire (carte détaillée)
- **Indicateurs de delta sur la liste** : badge vert/rouge sans ouvrir la carte
- **Feed chronologique inverse** : scroll fluide, sans pagination

## Anti-Patterns to Avoid

- Carte dès l'accueil (navigation unité par unité imposée)
- Grille de cartes compactes (illisible à petite taille)
- Tableau de stats style tableur (trop dense pour consultation rapide)
- Navigation séquentielle par unité (carousel/onglets)

## Design Inspiration Strategy

**Décision ouverte : densité de la carte d'unité**
- Piste A (idéale) : stats de base + deltas
- Piste B (fallback) : deltas uniquement si trop chargé
À trancher par test de lisibilité réel sur mobile.
